# T12 copied-fork CtxPack data: source and target contract

This is a migration design ledger, not a completed migration or an authorization to retire the integrated fork. The selected source is an independently digested copy of the **current fork** SQLite database; native and extension rows must be restored into the one selected target graph without writing the source, weakening the native migration ledger, or disclosing unrelated workspaces.

## Source-to-target mapping

| Current fork source | Owned target in the selected native database | Preservation constraint |
| --- | --- | --- |
| `ctx_pack` | `cm_ctx_pack` | Preserve IDs, workspace and creator IDs, unique `(workspace_id,created_by_user_id,create_idempotency_key)`, sensitivity, exact `tags_json`, content hash, revisions, counters, timestamps and tombstones. Do not recreate with catalog `create`, which would assign new IDs and counters. |
| `ctx_pack_fragment` | `cm_ctx_pack_fragment` | Preserve fragment IDs, ordinal, text/hash/byte/token values, source fields and exact optional source JSON. Verify each parent and source workspace; reconstruct and compare the ordered canonical whole-pack hash before import. |
| `ctx_pack_keyword` | `cm_ctx_pack_keyword` | Preserve ordinal/display/normalized keyword, uniqueness and sequence; never reconstruct normalization from title or fragment text. |
| `ctx_pack_pin` | `cm_ctx_pack_pin` | Preserve workspace/user scope, pack relation and immutable original pin time, including pins owned by users other than the migration caller. |
| `ctx_pack_fts` | `cm_ctx_pack_fts` | Rebuild from validated **live** imported packs, ordered fragments and keywords with the same `unicode61 remove_diacritics 2` tokenizer; do not copy SQLite virtual-table shadow rows or index deleted packs. Verify search results and exact workspace/private filtering after import. |
| `context_capsule` | `cm_context_capsule` | Preserve stable capsule ID, workspace, purpose, content hash, original validated JSON body, creator/budget JSON, creation/expiry time. The capsule audience/creator and references cannot be regenerated by materialization without changing identity. |
| `ctx_pack_usage_admission` | `cm_ctx_pack_usage_admission` | Preserve `(ctx_pack_id,session_input_id,time_recorded)` only when both the pack and native target `session_input` exist in the authorized copy scope; maintain existing `attached_count` and `last_attached_at` without recounting imported use. |
| OperatingChat `functionality_instance` configuration, workspace block/owner records | `cm_operating_chat_binding` plus future observed host instance/authority storage | Existing `sessionBinding.mode='owned'`, session ID, generation, instance revision and placement require source-supported codecs and host-verified layout. The new binding table is **not** a replacement for the original instance or workspace; a blind row copy or invented host authority is invalid. |

Source declarations: retained `packages/core/src/ctxpack/sql.ts:11–132`, `packages/core/src/context-broker/sql.ts:14–28`, `packages/core/src/workspace/{sql,operating-chat-context,operating-chat-session}.ts`. Target schema: `modular/packages/adapters-opencode/src/{ctxpack-catalog,ctxpack-capsule,ctxpack-usage,operating-chat-binding}.ts`. Source fork migration scripts and native `migration` ledger remain separate from target `cm_migration` IDs `0007`–`0010`.

## Import boundary and rejection matrix

1. Bound the image size; detach caller bytes; verify the exact external SHA-256 digest before opening a read-only isolated SQLite reader. Inspect required source table/column sets, reject missing or unexpected runtime versions, and close the reader on both failure and success. Never read the live fork database from the running application.
2. Authorize every requested workspace against its actual owner **before any source content is read** and again inside a single selected `EventBoundary.transaction` on the target. Reject absent owner, foreign pack/fragment/pin, missing parent/Session, corrupt JSON/hash/ordinal, mismatched content or target collision with a changed row. An exact repeat may reconcile only if every imported row and index identity is unchanged; no partial "already migrated" success.
3. Import packs, fragments, keywords, pins, capsules, usage and FTS as one consistency unit with the corresponding Session copy/rollback plan. Verify exact identity, counts, tombstones, read visibility, search and no public body leakage after target reopen; an injected failure halfway through must leave the target rows, migration ledger, public notifications and native Session data unchanged.
4. A deterministic source/target before-and-after digest and a reversible backup/rollback drill must precede gate promotion. A migration of only the first five tables is a deliberately **partial** T12 slice; it cannot close G4 or license source removal.

The representative `modular/packages/adapters-opencode/src/fork-session-copy.ts` already verifies a copied Session image, but intentionally rejects histories it cannot reconstruct and ignores product tables. It must not be described as a complete product migration.
