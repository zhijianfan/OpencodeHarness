## 2. Frozen group (`groups/ctxpack.ts`) — group id `server.workspace.ctxpack`, root `/api/workspace/:workspaceID/ctxpack`

Endpoints (params `{ workspaceID: Workspace.ID }` on every endpoint; `:ctxPackID` param
on the id-scoped ones; group id `server.workspace.ctxpack`; SDK surface after M1 will be
`client.v2.workspace.ctxpack.<name>`):

```text
POST   /api/workspace/:workspaceID/ctxpack                       -> workspace.ctxpack.create    (payload CtxPackCreateRequest)
GET    /api/workspace/:workspaceID/ctxpack/:ctxPackID            -> workspace.ctxpack.get       (success CtxPack.Info)
GET    /api/workspace/:workspaceID/ctxpack                       -> workspace.ctxpack.list      (query params -> CtxPackListRequest, defaults below)
PATCH  /api/workspace/:workspaceID/ctxpack/:ctxPackID            -> workspace.ctxpack.patch     (payload CtxPackPatchRequest)
DELETE /api/workspace/:workspaceID/ctxpack/:ctxPackID            -> workspace.ctxpack.remove    (payload { expectedRevision })
POST   /api/workspace/:workspaceID/ctxpack/:ctxPackID/restore    -> workspace.ctxpack.restore   (payload { expectedRevision })
POST   /api/workspace/:workspaceID/ctxpack/:ctxPackID/materialize-> workspace.ctxpack.materialize(payload CtxPackMaterializeRequest, success CtxPackMaterializeResult)
```

List query defaults (the group's list endpoint defines these as optional query fields with
defaults via `.pipe(Schema.optional, Schema.withDefault(...))` idiom — mirror how existing
groups handle optional query params, e.g. groups/workspace.ts):

```ts
{ query: "", keyword: null, sourceBlockID: null, sourceFunctionalityID: null, sourceKind: null,
  sensitivity: null, createdAfter: null, createdBefore: null, includeDeleted: false,
  sort: "created-desc", cursor: null, limit: 30 }
```

Limit is clamped/validated to 1–50 by schema check; malformed cursor string decodes as a
typed request error (cursor stays a plain string at the wire level).

Error schemas (TaggedErrorClass each, httpApiStatus noted) — these serialize the frozen
domain tags to stable client codes:

```text
CtxPackNotFoundError           { ctxPackID, message }        404
CtxPackDeletedError            { ctxPackID, message }        404  (plan: deleted treated as not-found-ish for get; keep distinct)
CtxPackRevisionConflictError   { currentRevision, message }  409
CtxPackContentChangedError     { currentContentHash, message } 409
CtxPackInvalidSelectionError   { reason, message }           400
CtxPackBudgetExceededError     { bytes, estimatedTokens, message } 400
CtxPackSecretSourceDeniedError { clientFragmentID, message } 400
CtxPackCrossWorkspaceDeniedError { sourceWorkspaceID, message } 400
CtxPackPermissionDeniedError   { operation, message }        403
CtxPackSearchCursorInvalidError { message }                  400
```

`materialize` response NEVER includes capsule contents — success type is the frozen
