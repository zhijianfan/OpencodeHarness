## 4. Frozen repository interface (C1/X1/C2/Q1 consume this EXACTLY)

```ts
namespace CtxPackRepository {
  interface Create { workspaceID: string; createdByUserID: string; title: string; keywords: string[]; sensitivity: CtxPack.Sensitivity; fragments: Array<{ clientFragmentID: string; text: string; source: CtxPack.Source }>; idempotencyKey: string; now: number }
  interface Patch { workspaceID: string; ctxPackID: CtxPack.ID; expectedRevision: number; patch: { title?: string; keywords?: string[]; sensitivity?: CtxPack.Sensitivity }; now: number }
}
interface CtxPackRepository {
  create(input: CtxPackRepository.Create): Effect.Effect<CtxPack.Info, CtxPackError>
  get(workspaceID: string, ctxPackID: CtxPack.ID, includeDeleted: boolean): Effect.Effect<CtxPack.Info, CtxPackError>
  patchMetadata(input: CtxPackRepository.Patch): Effect.Effect<CtxPack.Info, CtxPackError>
  list(input: CtxPackListRequest): Effect.Effect<CtxPackListResult, CtxPackError>
  softDelete(workspaceID: string, ctxPackID: CtxPack.ID, expectedRevision: number): Effect.Effect<CtxPack.Info, CtxPackError>
  restore(workspaceID: string, ctxPackID: CtxPack.ID, expectedRevision: number): Effect.Effect<CtxPack.Info, CtxPackError>
  recordUse(workspaceID: string, ctxPackID: CtxPack.ID, usedAt: number): Effect.Effect<void, CtxPackError>
}
```

Behavior: `create` assigns server IDs/ordinals/timestamps, revision 1; idempotent on
`(workspace_id, created_by_user_id, create_idempotency_key)` — duplicate key returns the
existing pack. `get` returns `CtxPackDeleted` when `deletedAt !== null` and
`includeDeleted=false`, `CtxPackNotFound` when absent. `patchMetadata` enforces
`expectedRevision` (else `CtxPackRevisionConflict`), increments revision, preserves
contentHash/fragments. `softDelete` sets time_deleted; `restore` clears it. `recordUse`
increments attached_count, sets last_attached_at = max(current, usedAt). List: default
excludes deleted; `includeDeleted=true` includes them. Cursor = opaque
URL-safe-base64 JSON of `{version:1, sort, value: string|number|null, id: string}` —
implement encode/decode here (decode rejects unknown version / mismatched sort / missing
id → `CtxPackSearchCursorInvalid`); every sort's cursor uses (sort value, id) keyed
pagination. totalEstimate: return a COUNT(*) estimate for the same predicate (exact count
is fine). Sort values: created-desc/asc → time_created; updated-desc → time_updated;
title-asc → title; tokens-desc → estimated_tokens; most-attached → attached_count;
recently-attached → last_attached_at. SQL injection safety: FTS query text is bound
through parameters; never interpolate raw query strings.
