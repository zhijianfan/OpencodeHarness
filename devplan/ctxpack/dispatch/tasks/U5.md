text AND `clearAfterAdmission()`. On failure: restore text and
`restoreAfterFailure(snapshot)`; materializations the user explicitly removed while the
request was pending stay removed (store exposes remove; you snapshot at send time so
restore returns exactly the send-time set). Queue/steer keep their existing busy/idle
