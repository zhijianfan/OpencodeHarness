## 4. `materialize` behavior (frozen)

1. Capability: `CapabilityService.require({ userID: actor.userID, operation:
   "ctxpack.materialize", subject: { type: "CtxPack", workspaceID, ctxPackID,
   sensitivity, createdByUserID } })` — needs pack sensitivity/owner, so fetch the pack
   first (repo.get includeDeleted=true). AND `CapabilityService.require({ operation:
   "chat.context.attach", subject: { type: "FunctionalityInstance", workspaceID,
   instanceID: request.targetInstanceID, functionalityID: request.targetFunctionalityID } })`.
2. Pack checks: not found → `CtxPackNotFound`; deleted → `CtxPackDeleted`;
   `pack.contentHash !== request.expectedContentHash` → `CtxPackContentChanged`.
3. Build the capsule exactly:

```ts
const capsule: StoredCapsule = {
  id: newContextCapsuleID(),                 // "ctxkpsl_" + ascending (mirror S1 id pattern; local helper)
  version: 1,
  workspaceId: pack.workspaceID,
  createdBy: { userId: actor.userID, instanceId: request.targetInstanceID },
  purpose: "ctxpack-attachment",
  audience: [request.targetFunctionalityID],
  summary: pack.title,
  facts: [
    { key: "ctxpack.id", value: pack.id, sourceRef: ctxPackRef, sensitivity: pack.sensitivity },
    { key: "ctxpack.fragmentCount", value: pack.fragments.length, sourceRef: ctxPackRef, sensitivity: pack.sensitivity },
  ],
  references: [ctxPackReference, ...pack.fragments.map(fragmentToContextReference)],
  artifactRefs: [], recentEvents: [],
  budget: DefaultInteractiveContextBudget,
  contentHash: pack.contentHash,
  createdAt: Date.now(),
  expiresAt: null,
}
```

   `ctxPackRef = { type: "ctxpack", id: pack.id }`; `ctxPackReference = { kind:
   "ctxpack", ref: ctxPackRef, label: pack.title, contentHash: pack.contentHash,
   sensitivity: pack.sensitivity }`; `fragmentToContextReference(fragment) = { kind:
   "ctxpack.fragment", ref: { type: "ctxpack-fragment", id: fragment.id }, label:
   fragment.source.label ?? `Fragment ${fragment.ordinal + 1}`, summary: fragment.text,
   contentHash: fragment.contentHash, sensitivity: fragment.source.sensitivity }` —
   fragment text appears ONLY in the capsule reference summary (immutable durable
   store), never in events/errors/logs/result projections.
4. `ContextCapsuleStore.store(capsule)`. Result: `{ contextCapsuleID: capsule.id,
   sourceCtxPackID: pack.id, label: pack.title, contentHash: pack.contentHash,
   estimatedTokens: pack.estimatedTokens }`. **No usage counter change** (usage is Q1/C2's
   post-admission concern).

## 5. `snapshotForSessionInput` behavior (frozen — Q1 calls this BEFORE durable admission)

1. Capability: `chat.context.attach` on the target FunctionalityInstance subject.
2. Zero attachments → return empty snapshot `{ version: 1, attachments: [], byteLength:
   0, estimatedTokens: 0, createdAt: Date.now() }`.
3. Duplicate `contextCapsuleID` in attachments → reject `CtxPackSnapshotDuplicateCapsule`
   (whole snapshot fails).
4. > 8 attachments → reject (CtxPackInvalidSelection, reason "too-many-attachments").
5. For each attachment (IN ORDER): `ContextCapsuleStore.get(actor.workspaceID,
   contextCapsuleID)`; missing → CtxPackCapsuleMissing; expired → CtxPackCapsuleExpired.
   Capability check `"ctxpack.read"` on the source CtxPack subject (source.ctxPackID +
   pack row via repo.get includeDeleted=true — deleted pack → CtxPackDeleted).
   `capsule.contentHash !== attachment.contentHash` → CtxPackContentChanged.
6. Materialize fragment texts: read the capsule's references where
   `ref.type === "ctxpack-fragment"`; for each, look up the fragment text from the
   CURRENT pack row (repo.get, fragments in ordinal order) by `ref.id`; missing
   fragment → reject whole snapshot (CtxPackContentChanged). Build the snapshot
   fragments `{ text, source, contentHash }` from the pack row (immutable by contract).
7. Budget: aggregate `byteLength` (JSON.stringify bytes) and `estimatedTokens`
   (`Math.ceil(bytes/4)` over the fragment texts) against `input.budget`; over → reject
   whole snapshot `CtxPackSnapshotOverBudget`.
8. Return a DEEP IMMUTABLE plain object (deep clone / Object.freeze recursively; later
   pack mutation/deletion cannot change the returned object — test this).
9. NO Session writes, NO usage-table writes, NO events. Diagnostics/logs carry bytes and
   counts only — never text.
