# Track G1 — JavaScript SDK Regeneration

## Mission

Regenerate the JavaScript SDK from the frozen P1 protocol contract and verify deterministic output.

Target branch: `feature/UnrealViewer`.

## Dependencies

- A0 shared contracts.
- P1 protocol contracts merged and frozen.

This track is intentionally sequential after P1.

## Files

### Generated only

```text
packages/sdk/js/src/**
```

The exact generated files are determined by:

```bash
node packages/sdk/js/script/build.ts
```

Do not manually edit generated files.

## Procedure

1. Branch from the exact P1 merge commit.
2. Confirm the working tree is clean.
3. Run:

```bash
node packages/sdk/js/script/build.ts
```

4. Review the diff and confirm it includes:
   - workspace `coderModel` field/patch typing
   - MasterAgent get/ensure/reset client operations
   - shared binding/request/result types as generated by repository conventions
5. Run the generator a second time:

```bash
node packages/sdk/js/script/build.ts
```

6. Confirm the second run produces no additional changes.
7. Typecheck the SDK package.

## Important boundaries

- Do not modify protocol files.
- Do not hand-fix generated types.
- Do not add app adapters; M2 owns handwritten client integration.
- Do not include unrelated formatting or dependency changes.

If generation fails because of a protocol defect, stop and return the issue to P1. Do not patch generated output to bypass the failure.

## Verification

```bash
node packages/sdk/js/script/build.ts
node packages/sdk/js/script/build.ts
bun --cwd packages/sdk/js typecheck
```

Also confirm the second generation run has a clean diff relative to the first generated state.

## Deliverable

One commit containing generated SDK output only, plus a note identifying the P1 commit used as input.

## Handoff to M2

List the exact generated method names and import paths for:

```text
workspace coderModel patch
masterAgent get
masterAgent ensure
masterAgent reset
```
